    - Consumption importance <-> Leisure importance
    - Cannot be uniquely determined from data alone
    - Multiple parameter combinations explain the data equally well (or better!)

================================================================================
WHY ULTRA_MINIMAL CONVERGES TO SAME LL AS MINIMAL_THETA0
================================================================================

Both achieve LL = -7862.91 DESPITE having different parameter counts:

  minimal_theta0 (17 params):
    - 4 leisure thetas (theta_l_sm, theta_l_sf, theta_l_m, theta_l_f)
    - 3 consumption thetas (theta_c, theta_c_sm, theta_c_sf)
    - Total: 7 Box-Cox curvature parameters

  ultra_minimal (10 params):
    - NO theta parameters (box_cox_exponent: null for both)
    - Only 7 fewer parameters than baseline

FINDING: The 7 theta parameters contribute ZERO to model fit!
  - Setting theta=0 (log utility) loses NO likelihood
  - These parameters are UNIDENTIFIED
  - Classic identification failure: parameters exist but are not estimated

IMPLICATION: The model naturally prefers LOG UTILITY (theta=0)
  - Box-Cox flexibility is not needed
  - Simpler log form is sufficient
  - ultra_minimal is MORE EFFICIENT use of parameters

================================================================================
WHY POOLED SPECS FIND BETTER SOLUTIONS
================================================================================

The pooled_consumption and pooled_leisure specs achieve:
  - 102.51 IMPROVEMENT in log-likelihood
  - Same improvement despite different pooling strategies
  - Better fit than baseline with FEWER total parameters (14 vs 17)

HOW IS THIS POSSIBLE?

The key: PARAMETER TRADE-OFFS

When pooling consumption (forcing beta_c_sm = beta_c_sf = beta_c initially),
the optimizer compensates by:
  - RAISING leisure intercepts (especially for singles)
  - This allows higher utility from leisure to offset lower consumption variation

Result: The model achieves:
  1. Lower consumption heterogeneity (more efficient parameterization)
  2. Higher leisure values (compensates for consumption pooling)
  3. BETTER overall fit (+102.51 LL)

WHAT THIS REVEALS: Identification Problem #1
  The baseline model has redundant ways to explain labor supply:
    - Via consumption preference heterogeneity, OR
    - Via leisure preference heterogeneity
  Cannot uniquely separate these effects

================================================================================
IDENTIFICATION PROBLEMS DIAGNOSED
================================================================================

PROBLEM 1: Unidentified Box-Cox Curvature Parameters
  Evidence: theta parameters all=0 (at bounds)
  Impact: 7 parameters contribute nothing
  Solution: Remove them (use ultra_minimal or fixed-theta specs)

PROBLEM 2: Non-Unique Parameter Combinations
  Evidence: Multiple specs achieve similar/better fits with different params
  Impact: Consumption and leisure utilities are trade-offs
  Solution: Need more structure or external information to separate them

PROBLEM 3: Multiple Local Maxima
  Evidence: Different optimization paths lead to different LL values
  Impact: Solution depends on initialization and constraints
  Solution: Explore solution space thoroughly; use global optimization methods
