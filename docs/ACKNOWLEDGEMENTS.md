# Acknowledgements

This RURO/MNL project benefited from discussions, reference material, and
implementation comparisons involving Stijn Van Houtven.

The package-facing terminology should describe the implemented methodology as
RURO: Random Utility Random Opportunity modeling with sampled opportunity sets,
proposal-density correction, and additive opportunity components.

Personal names are kept here for acknowledgement and in original reference
files where authorship/provenance should remain intact. They should not be used
as the generic name of the package, model class, estimation pipeline, or
specification family.
