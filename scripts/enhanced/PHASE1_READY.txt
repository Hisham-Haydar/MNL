     - Consumption: independent (_sm ≠ _sf ≠ base)

EXPECTED OUTCOMES
=================

Each estimation will:
  ✓ Load 14 parameters with pooling initialization constraints
  ✓ Optimize for ~15-20 minutes (SciPy L-BFGS-B)
  ✓ Produce log-likelihood and parameter estimates
  ✓ Show whether optimizer keeps pooled params equal

Interpretation:
  If LL values are SIMILAR across specs:
    → Pooling constraints are NOT binding
    → Pooled parameters are unidentified
    → Simpler specs are PREFERRED

  If LL values DIFFER significantly:
    → Pooling constraints ARE binding
    → Pooled parameters lose fit
    → More complex spec is NEEDED
